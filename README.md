# Infografía interactiva — Rendición cognitiva

Infografía interactiva sobre la dificultad creciente de *rendir cognitivamente* en actividades educativas y todas las actividades en general.

## Publicación

Vivo en GitHub Pages:

https://linapsp.github.io/infografia-rendicion-cognitiva/

## Contenido

- `index.html` — infografía interactiva (autocontenida, sin dependencias externas)
- `styles.css` — estilos, con tipografías locales (Newsreader Variable + IBM Plex Mono)
- `app.js` — lógica de interacción
- `assets/` — ficheros woff2 y licencia OFL de Newsreader

Las vistas previas (`preview-*.png`) muestran el concepto, el flujo y la página completa.

Todo se despliega directamente en GitHub Pages desde `main` (raíz del repositorio).
